# Readiness Gate

Check whether an AI generated plan is ready to execute before anyone spends time or money on it.

The rule: do not ask AI for a plan first. Ask whether a plan is allowed.

## What is here

- [The full guide](readiness-gate-for-non-technical-operators.md): why AI plans fail in real execution, the 12 point checklist, readiness levels, worked examples, evals, and a workshop script.

Written for interns, operators, project managers, founders and assistants who use AI for serious planning without a technical background.
